A tool portal is useful on day one. What makes it stick is everything that happens *around* the tools — the collaboration, the shared knowledge, the discovery. Three recent additions do exactly that.

## Real-time collaboration

Work together in the same applet at the same time. You get live data sync, presence indicators showing who's online, and `@`-mentions that fire off instant notifications. It turns a personal tool into a shared workspace without any extra setup.

## Prompt library

The quality of an AI-built tool depends on the prompt behind it. The prompt library lets your team browse ready-made prompts, save their own, and copy the best ones with a single click — with categories, search, and usage tracking so the good techniques spread.

## Marketplace

Discover public applets built by the wider community. Preview any listing, install a private copy into your toolbox in one click, or publish your own creations for others to build on.
